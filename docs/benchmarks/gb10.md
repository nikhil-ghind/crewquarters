## How to run on the GB10

Two tools cover PLAN.md section 22 on the device. Record both outputs next to this report.

**1. Model benchmark (real vLLM).** The model gateway is reachable only on the private Compose network, so run the script inside the gateway container of the installed appliance stack (Compose project `crewquarters`, from `compose.appliance.yaml`, with the host runtime daemon):

```bash
docker cp infra/scripts/benchmark_model.py crewquarters-model-gateway-1:/tmp/benchmark_model.py
docker exec crewquarters-model-gateway-1 sh -c \
  'python /tmp/benchmark_model.py --model local.general.small --runs 5 \
     --gateway http://127.0.0.1:8090 --token "$CQ_INTERNAL_SERVICE_TOKEN"' > gb10-small.json
```

Copy the cold start, first-token, decode/prefill and memory numbers into the table above. Repeat for `local.general.quality`, and note the concurrent-request behavior (2 and 4 parallel streams).

**2. Platform harness (the same one as `docs/benchmarks/laptop.md`).** From a checkout on the device (arm64 images build natively):

```bash
make perf                                   # separate `cqperf` stack on 127.0.0.1:18094, torn down afterwards
PERF_EMBEDDING_MODE=local make perf         # the default; measures the pinned ONNX embedder on the Arm cores
uv run python infra/scripts/perf/perf.py report tmp/perf/results.json
```

- It uses its own Compose project, ports, image tags and runtime-daemon networks, so it does not disturb the installed appliance. Do not run it during a demo: it loads the CPU and the database.
- On the device, the harness still uses the dev mock model catalog (`catalog/models/dev`), so its model section measures platform overhead. Real model numbers come from step 1.
- Knowledge query p95 at 100k chunks is a target on this hardware (PLAN.md section 22). Report the exact-search and ad hoc HNSW rows from the harness, and decide whether an HNSW migration is needed. On the laptop, exact search was 426 ms p95.
- Also record the embedding ingestion rate (chunks/s): on the laptop it is bound by CPU embedding.
- Record fresh core setup time separately, following the installer runbook: `.deb` install through the setup wizard. The harness's setup section covers only `compose up` plus API setup.
